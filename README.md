# Zargham Hassan Portfolio

React + TypeScript + Vite portfolio source.

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP and open the folder in VS Code.
3. Open the terminal in the project folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Build
```bash
npm run build
npm run preview
```

## Profile photo
This source-only ZIP intentionally does not include an image asset. The hero portrait uses a CSS initials placeholder, so the project runs without an image file.
